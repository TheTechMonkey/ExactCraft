# Exact Craft

Exact Craft adds a compact quantity control directly to Satisfactory's Craft Bench and Equipment Workshop interfaces.

Select a recipe, choose an exact number of crafting cycles with the slider or numeric field, and craft normally with the mouse or Space. Crafting stops automatically when the selected quantity is complete.

## Features

- Exact manual-crafting quantities
- Dynamic range based on the amount currently affordable
- Slider, keyboard entry, mouse, and controller-friendly controls
- Infinity mode for vanilla continuous crafting
- MAX shortcut for the maximum currently affordable amount
- Craft Bench and Equipment Workshop support
- Configurable whole-number manual crafting speeds from 1x to 20x
- 28 localized tooltip languages
- No save-game changes

## Quantity behavior

The selected value is the number of recipe crafting cycles, not necessarily the number of output items. For example, if one crafting cycle produces four screws, selecting five produces twenty screws.

## Requirements

- Satisfactory 1.2.4 (game build 502094 or newer)
- Satisfactory Mod Loader 3.12 or newer

## Building

This is an Unreal Engine 5.6.1 Satisfactory mod. Place the plugin in the `Mods/ExactCraft` directory of a configured Satisfactory modding project, then build or package it with Alpakit.
